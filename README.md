# OCI-Data-Science-Professional
OCI Data Science Professional Progress

This repository documents my learning journey through the Oracle Cloud Infrastructure (OCI) Data Science Professional course. The course provides hands-on experience across the entire machine learning lifecycle, including workspace setup, model training, deployment, and MLOps practices, leveraging OCI's suite of services.

🚀 Course Objectives

Understand and implement the end-to-end machine learning lifecycle on OCI.

Configure and manage OCI Data Science workspaces and projects.

Utilize the Accelerated Data Science (ADS) SDK for streamlined workflows.

Apply MLOps best practices for automation, monitoring, and scaling.

Integrate OCI services like OCI Vault, Object Storage, Data Flow, Data Labeling, and Generative AI.

📚 Key Learnings

OCI Data Science Environment: Workspace/project management, JupyterLab, Conda environments, code repositories, and secure access using OCI Vault.

Machine Learning Lifecycle: Data access, preprocessing, visualization, model training (AutoML & ADSTuner), evaluation, explanation (global & local), and serialization.

Model Deployment: Deploy models with TensorFlow, Hugging Face, LangChain (RAG), autoscaling, and OCI operators.

MLOps Practices: Jobs creation, pipeline automation, monitoring, logging, and scaling deployments.

Related OCI Services: Data Flow (Spark applications), Data Labeling, Generative AI integration, and access to OCI Open Data.

💡 Benefits

Gain hands-on experience managing ML workflows in the cloud.

Learn to deploy scalable, secure, and production-ready ML solutions.

Understand best practices for integrating multiple OCI services into real-world business applications.
